# rb

Personal CLI assistant built in Go using Cobra. 

It combines AI queries with developer tools, letting you interact with AI, open web targets, and trigger workflow automations from the shell.

### Commands

```bash
rb ai "ask a question"
rb open website
rb password
rb ptui
```

### Requirements

- Go 1.26.6
- `pass` for password management

### Install

```bash
git clone [https://github.com/rober0xf/rb.git](https://github.com/rober0xf/rb.git)
cd rb
go install
```
